1. Arquitectura del Modelo Multiruta

El sistema implementa un entorno de simulación basado en Gymnasium donde un agente de Aprendizaje por Refuerzo (PPO - Proximal Policy Optimization) interactúa con series temporales históricas extraídas de los datasets de Renfe mediante flujos ETL en PySpark.

2. Restricciones de Gobernanza y Leyes de Negocio

Para evitar comportamientos anómalos o subidas desreguladas que vulneren las políticas comerciales, el motor aplica de forma automática dos barreras físicas inquebrantables:

  • Techo Regulatorio (Price Ceiling): Ninguna recomendación de la IA puede superar el precio máximo histórico registrado para cada corredor específico.
  • Suelo de Rentabilidad (Price Floor): Se respeta un umbral mínimo de tarifa para proteger los márgenes operativos ante descuentos agresivos.

3. Despliegue y Arquitectura Frontend

El backend genera una matriz de decisión jerárquica exportada como objeto JSON estático (cerebro.js), permitiendo una inferencia instantánea en el navegador web cliente sin latencia de servidor, integrada con visualizaciones científicas mediante Plotly.js y maquetación corporativa.
